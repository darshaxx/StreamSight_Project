STREAMSIGHT - OTT VIEWER DROP-OFF DASHBOARD
===========================================

FILES
- index.html : page structure and dashboard sections
- style.css  : layout, colors, responsive design, cards and buttons
- script.js  : charts, sidebar navigation and illustrative demo interaction

HOW TO RUN
1. Extract this folder from the ZIP.
2. Open the folder in Visual Studio Code.
3. Open index.html.
4. Either double-click index.html in File Explorer to open it in your browser,
   or use the VS Code Live Server extension and click "Go Live".

IMPORTANT
The displayed CA2 model metrics are based on the results supplied for the project.
The Prediction Demo uses illustrative front-end rules only. It is not connected to
the trained Python / scikit-learn model. To make real predictions, a backend API
must load the trained model pipeline and receive the form inputs.
